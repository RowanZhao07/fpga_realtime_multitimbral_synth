# 演示视频工程

最终时间表为 176.967 秒（2 分 56.967 秒），1280×720、30 fps。第一幕取总览素材 0.5～18.5 秒，以 1.5 倍画面速度输出 12 秒；旁白只去除头尾少量静音，语速保持 1.0。其余演奏、节拍器与配音保持原速。

## 文件

- `render.py`：独立剪辑、字幕、旁白混音与成片校验程序。
- `project.json`：九幕素材、帧数、字幕和配音时间表。
- `节拍器台词.txt`：三条可直接录音的台词与时间安排。
- `media/`：本地原片、开场、手机记录图与 `narration/` 录音，不纳入 Git。
- `final_20261104/`：本地成片、SRT、时间表及校验结果，不纳入 Git。

原始视频及既有剪辑版本保留在本地，发布脚本不依赖旧版 Python 脚本的级联导入。

## 复现

Python 3.10+，安装 `numpy`、`Pillow`，并准备 FFmpeg/ffprobe 与可用中文字体。

```powershell
python videos/render.py --media-dir videos/media --output-dir videos/final_20261104 --ffmpeg '<FFmpeg>/bin/ffmpeg.exe' --font '<中文字体文件>'
```

按 `project.json` 中的相对文件名放入原始素材。旁白使用已有的 48 kHz 录音；脚本不调用 TTS 服务、不改变讲话速度。节拍器三条录音为可选输入：尚未放入时输出现场原声加字幕；放入后自动配入并压低对应背景声。超出安排时长的录音会报错，不自动加速。

输出 `validation.json` 记录总时长、逐条录音哈希与原速设置、音频峰值和成片哈希。成片执行完整解码检查，时长超过 180 秒即报错。
