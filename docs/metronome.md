# 电子节拍器

当前 EXPR M3 8T，默认关闭、120 BPM、4/4。节拍声由 FPGA 独立合成，不占用 32 个乐器声部；跟随主音量，保持强弱拍与 HDMI 拍点一致。

| 组合键 | 功能 |
|---|---|
| LED_TEST/X0 + VIB/C3，保持约 0.5 s | 开关节拍器 |
| LED_TEST/X0 + TONE/C0，保持约 0.5 s | 2/2 → 2/4 → 3/4 → 4/4 → 6/8 |
| LED_TEST/X0 + VOL+/C2 | 立即加 1 BPM，保持时每 0.1 s 加 1，最高 240 |
| LED_TEST/X0 + VOL−/C1 | 立即减 1 BPM，保持时每 0.1 s 减 1，最低 40 |

可先保持 X0，再逐次操作其他功能键。组合结束后抑制单键误触发；X0 单独按住仍检查 13 路键灯。调速在节拍器关闭、演奏与 GUIDE 状态下均可使用。

| 拍号 | BPM 计拍单位 | 每小节发声顺序 |
|---|---|---|
| 2/2 | 二分音符 | 强、弱 |
| 2/4 | 四分音符 | 强、弱 |
| 3/4 | 四分音符 | 强、弱、弱 |
| 4/4 | 四分音符 | 强、弱、次强、弱 |
| 6/8 | 附点四分音符 | 强、弱、弱、次强、弱、弱 |

6/8 每个 BPM 大拍细分为三个八分音符。120 BPM 时，4/4 每 0.5 s 一声，6/8 每 1/6 s 一声。采用保留小数余量的相位累计，调速不重置当前相位；开启或切换拍号从第一强拍开始。GUIDE 的曲谱 BPM 独立，通过串口 B 命令设置。

强／次强／弱拍基频为 2000／1600／1200 Hz，使用短起音与指数衰减。M2 的节拍声振幅为 M1 的 4 倍（+12.04 dB），强弱比例与拍点保持。满主音量的仿真峰值分别为 9892／7764／5268；最终混合采用有符号饱和，`V0` 同时静音琴声和节拍。

左下角显示 BPM、拍号、计拍单位与当前拍点。频谱由 512×88 等比例压缩至 256×44，每对相邻频点保留较大值，FFT 点数和约 0～6 kHz 的范围保持。Y 弯音使用 UART `Y0/Y1`，X0+C3 作为节拍器开关。

M2 定向回归覆盖 8767 帧 I²S、主音量静音、关闭后琴音旁路、正负饱和及完整屏幕。与 M1 对齐的 293414 个采样点逐点验证 4 倍增益和拍点不变。M3 保留节拍声实现，重新通过 8767 帧 I²S 核心回归。当前版本、时序及构建信息见[M3 优化验证](scheduler_optimization.md)，历史测量见[M2 发布基线](release_verification.md)。
