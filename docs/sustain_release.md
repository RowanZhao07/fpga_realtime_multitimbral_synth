# 延音版本提交说明

## 贡献者与修改理由

本轮由 **chenxi639**（提交邮箱：chentseng908@gmail.com）提出需求并主导改进，Codex 协助实现、验证和整理文档；原项目及队友贡献保留在 Git 历史中。

原版本松键即进入释音，无法试听钢琴踏板的尾音效果。本轮在包络层保留松键后的声部，抬踏板后平滑释音，电钢琴的自然衰减时间约延长到四倍。保留真实按键边沿以支持同音重弹，并避免空踩产生音符或恢复已经释音的声音。

## 本次内容

- 完整二值延音输出链路、UART H0/H1 控制、未来硬件踏板的同步去抖后输入接口，以及离线、复位和测试模式保护。
- 正常工程默认关闭延音；新增默认 T1 电钢琴、延音开启的触摸调试工程，无需踏板，真实触摸才发声。
- 高云 IDE 工程与可移植配置、调试说明、延音实现报告、现有 54 条警告的核查说明。
- 延音包络、控制、音频及触摸调试测试，既有测试接口适配；音频对照分析工具。
- 构建脚本兼容 Gowin 1.9.12.04，并区分正常版与调试版；清理脚本保留 dist 中两种已生成的版本。

首次下载请按 [IDE 打开说明](../instrument/OPEN_IN_GOWIN.md) 恢复本地配置，然后自行在官方软件中综合、布局布线和烧录。本提交只交付源码、工程、测试与说明，不包含位流、许可文件或本机构建输出。

## 验证与范围

- 延音实现阶段已通过 34 项 RTL 回归及 8 项串口工具测试，音频/和弦/FFT 分析及壁纸逐像素检查通过。
- 加入默认延音触摸工程后，已通过 7 项相关 RTL 测试；回归入口现含 35 项测试，未宣称对最终版本重新完整运行全部 35 项。

- 2026-10-21 提交前复核：8 项串口工具测试通过，工程引用与配置路径检查通过，Git 空白检查通过，清理脚本仅预览通过；本次没有重新生成位流或执行实板烧录。

当前为 13 个固定音高声部，同音重弹复用声部。尚无物理踏板适配器、32 动态复音、半踏板、共振弦或踏板噪声模型；实板听感仍需后续验证。
