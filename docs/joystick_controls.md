# KY-023 + EC11 + 单 ADS1115 复用版

队友分支 `feature/joystick-shared-adc`（`85118b9`）基于 `1c9400b` 实现，2026-10-29 已快进合入本地 main，保留原作者与提交。组合工程 `instrument/instrument_joystick.gprj` 同时启用摇杆、EC11 和压力滤波；保留实测 3235 mV 满压力标定、76 音《遇见》GUIDE、32 声部和原音频输出。原有三个工程入口保持原输入行为。构建和实板验收状态见[验证报告](joystick_verification.md)。

## 操作方式

- 左拨降低一个八度，右拨升高一个八度，范围 C3..C6，默认 C4；拨住不连发。方向反了可设置顶层 `JOYSTICK_REVERSE=1`。
- 每次必须回中并取得连续 8 个中心区域的有效 ADC 样本才重新允许切换。中心默认 1650 mV，回中范围 ±300 mV，触发范围超过中心 ±800 mV。中间区域保持状态；上电或重连时偏置在一边不会切换。
- 按住 SW 开启已有颤音，释放关闭；默认低电平有效、10 ms 去抖。上电按住时先释放才能使用。按压期间禁止切换八度，释放后也需要回中。
- GUIDE 自动音区优先；GUIDE、校准模式和触摸掉线期间不接受手动八度事件，退出后回中再拨。已发声声部保持原音高，新音符使用新八度。
- 本组合工程不再使用 X0+C0..C3 切八度和单独 C3 触发颤音。C0 音色/回声、C1/C2 音量、C1+C2 GUIDE、四控制键校准、X0 灯测试保留。触摸音符输入仍需原来的两块 MPR121。
- 共享 ADC 掉线会同时使力敏与摇杆读数失效：力敏增益平滑回到主音量，摇杆停止切八度，恢复后先回中。触摸和 EC11 不依赖 ADC；SW 是独立数字输入，ADC 掉线时仍可按住产生颤音。

## 接线表（Tang Mega 60K NEO 的 J13）

| 信号 | 外设连接 | FPGA 接口 | FPGA 球位 |
|---|---|---|---|
| 共享 ADC SCL | 原 ADS1115 SCL | J13-15，保持原接线 | A20 |
| 共享 ADC SDA | 原 ADS1115 SDA | J13-16，保持原接线 | B20 |
| 力敏模拟量 | 原 FSR 分压节点 | ADS1115 AIN0 | 不直接接 FPGA |
| 摇杆横轴 | KY-023 VRx | 同一 ADS1115 AIN1 | 不直接接 FPGA |
| 摇杆按键 | KY-023 SW | J13-23 | A19 |
| 摇杆单独供电 | KY-023 的 `+5V` / VCC（本版实际约 3.3V） | **J13-9，配置完成后恒高；仅接一个低功耗摇杆** | B16 |
| EC11 A / B / SW | 保持原接线 | J13-8 / 7 / 6 | A13 / A14 / C13 |
| 公共地 | ADS1115、KY-023、EC11 共地 | J13-12 / 板上 GND | — |

J13 编号是连接器物理脚号，不是 FPGA 球位。J13-11 是 5V，不能当 GND；上述 SDRAM 扩展引脚不能再并接 SDRAM。针脚依据官方 [60K SDRAM 约束](https://github.com/sipeed/TangMega-60K-example/blob/main/sdram_neo/src/sdram.cst) 与 [NEO Dock-60K 原理图](https://dl.sipeed.com/fileList/TANG/Mega_138K_60K/02_Schematic/DOCK/Tang_Mega_NEO_Dock-60K_31004_Schematics.pdf) 的 J13 对照。

只需要原有一块 ADS1115，3.3V 供电，ADDR 接 GND（0x48）。AIN0 保持原 FSR 分压电路，AIN1 新接 KY-023 VRx。VRy、AIN2/AIN3 和 ALERT/RDY 暂不使用。2026-10-30 的 GPIO 供电版新增 J13-9/B16 输出，J13-10 仍留空。

单 ADC 采用单次转换轮询：写入 AIN0 配置 `C3E3` → 等待并轮询配置寄存器的 OS 位 → 确认转换完成 → 读取压力 → 写入 AIN1 配置 `D3E3` → 同样等待完成后读横轴，再循环。每次验证 MUX/PGA/MODE/DR，OS=0 时不读旧转换值。不是在连续转换时直接切 MUX 后立刻读寄存器。实现依据 [TI ADS1115 数据手册](https://www.ti.com/lit/ds/symlink/ads1115.pdf)。

860 SPS 是 ADC 转换速率上限，不是每个输入的更新速率；当前 100kHz I2C、默认等待 2ms，加配置写入/状态读取/数据读取，默认时序的总线模型仿真得到每通道间隔 6.65048 ms，约 150 次/秒，实板仍需测量确认。回中需 8 个有效横轴样本，约 53 ms；按键去抖独立于 ADC。共享设备故障会使两路同时无效，恢复从 AIN0 重新开始。

KY-023 电位器按约 3.3V 供电，GND 共地；不要因模块丝印 `+5V` 就把 5V 模拟输出送入本系统。供电略有压降时回中电压也会变化，需要实测。

### J13-9 GPIO 供电版：只带一个低功耗摇杆

用户在 20kΩ 档读到摇杆电源端电阻约 2.6，即约 2.6kΩ；按纯电阻静态负载估算，3.3V 下约 1.27mA，不等同于实测带电电流或接线无误证明。用户选择使用一个空闲 GPIO 为摇杆单独供电。组合版将 **J13-9（SDRAM0_D15 / B16）** 配置成 LVCMOS33、DRIVE=8、无弱上拉，配置完成后持续输出高电平，不随复位、摇杆操作或 ADC 掉线切断。非摇杆工程在此脚输出高阻。

依据 [GW5AT 数据手册 DS981，表 3-28](https://cdn.gowinsemi.com.cn/DS981E.pdf)，GW5AT-60 的 3.3V GPIO 支持 8mA 驱动档，在对应测试条件下 VOH 最低为 VCCIO-0.4V。GPIO 高电平不是精密稳压源，DRIVE=8 也不是限流/短路保护；仅适用于这一只已核对低功耗负载的摇杆，不得给 PCB、ADS1115、编码器、LED 或其他模块供电。

**接线前全部断电，摇杆电源线与 PCB 5V、J8/J9 电源或其他供电源完全断开。** 不得把 J13-9 接到 PCB 的电源母线、原 5V 焊点或其他供电输出。PCB 原 U1-9 未布线，优先直接从 FPGA J13-9 接到摇杆电源端，不能只接 U1-9 后假定已到摇杆。

| 摇杆端子 | 接线 |
|---|---|
| VCC（模块可能印 `+5V`） | **FPGA J13-9 / B16**，只接这一根供电线 |
| GND | FPGA J13-12 / PCB 公共地 |
| VRx | PCB U2-8，即 ADS1115 A1 |
| SW | FPGA J13-23，即 A19 |
| VRy | 留空 |

J13 的 9/10 是从 1/2 开始数的第五对针；下一对 **11/12 是 5V/GND**，不能错位。J13-9 只有下载本次 GPIO 供电版后才提供高电平；之前同名的旧位流没有此输出。SRAM 程序断电丢失，重新上电须重新下载。本版不保证 FPGA 配置期间的输出电压。

上电下载组合版后，先测摇杆 `+5V` 对 GND 的实际电压，应接近 3.3V，允许小幅压降；若明显低于 2.9V、重新掉到 0V 或开发板异常，断电检查接线与负载，不能靠增大 DRIVE 掩盖问题。然后确认 STICK L/R OCT、TOUCH ONLINE、ADC OK、GUIDE OFF；释放摇杆按键应为 VIB OFF，回中一秒后左右拨到底，观察左上角 OCTAVE 在 3～6 之间变化，松键重弹验证新八度。

中位参数仍为 1650mV：U2-8/A1 须回到 1.35～1.95V，并取得连续八个有效样本；低/高端需分别达到不高于 0.85V / 不低于 2.45V。仿真可检查 2.9V 供电对应的约 1.45V 中位仍能触发，实际负载压降和机械中位需要万用表确认。按住 SW 时禁止切八度，释放后须重新回中。

另有固定电源方案：官方底板 Rev 1.4 原理图第 19 页的 J8/J9 第 1、2 脚为 +3V3，第 3、4 脚为 GND；实际孔位必须按丝印/实物确认。用户此前报告某取电点空载约 3.3V、接摇杆降为 0V，但具体孔位未确认，不能将其认定为 PMOD 固定电源故障。固定电源与 J13-9 GPIO 供电必须二选一。

SW 默认按下接地，外接 4.7k~10k 上拉到 3.3V（FPGA 内部也启用上拉）。实测模块若是相反极性，可改 `JOYSTICK_BUTTON_ACTIVE_LOW`，同时按模块电路调整上下拉；不要把 5V 上拉接入 FPGA。原 I2C 线需上拉到 3.3V，优先使用模块已有上拉，避免重复并联过低阻值。洞洞板使用分开的电源/地母线，ADS1115 旁放 100nF 去耦，模拟线短、远离 HDMI/时钟；摇杆壳体单独固定，焊点不承担手部机械力。

## 除 EC11 和摇杆外，其他线怎么接

已有 PCB 上焊好的、此前能工作的线路保持不动。下面是核对表：如果模块已经通过 PCB 铜线接好，就不用再并一根杜邦线。先断电再插拔。

**先认接口：** J13 是开发板上靠 PCIe 的 2×20 排针。`J13-15` 就是它的第 15 脚，不是芯片上的 A15。按板上 1 脚标记确认方向，一列是 1、3、5……，另一列是 2、4、6……；不要凭照片的左右猜。第 11 脚是 5V，第 12 脚是地。J13 没有直接的 3.3V 电源脚，3.3V 继续取你 PCB 原有的 3.3V 电源点；地线都连在一起，称为“共地”。

| 找到哪个模块 | 模块上的字 | 接到哪里 |
|---|---|---|
| 触摸板 A（MPR121） | SCL / SDA | J13-1 / J13-2 |
| 触摸板 B（MPR121） | SCL / SDA | J13-13 / J13-14 |
| 两块触摸板 | VCC、GND、ADD | 分别接 3.3V、公共地、公共地；IRQ 不接 |
| 原 ADC 小板（ADS1115） | SCL / SDA | J13-15 / J13-16 |
| 原 ADC 小板 | VDD 或 VCC、GND、ADDR | 分别接 3.3V、公共地、公共地 |
| 原 ADC 小板 | A0 / A1 | A0 保留压力片分压点；A1 留给摇杆横轴；A2、A3、ALERT 不接 |
| 声音输出板（PCM5102） | BCK / LRCK / DIN | J13-3 / J13-4 / J13-5；有的模块把 LRCK 写作 LCK |
| 现有 PCM5102 底板 | VIN 或 5V、GND | J13-11 的 5V、公共地；仅针对此前已使用的带稳压底板 |
| PCM5102 | 音频插孔 | 插到有源音箱的 AUX/LINE IN；音箱用自己的电源 |
| PCB 灯驱动（74HC595） | SER / SRCLK / RCLK / OE | J13-17 / J13-18 / J13-19 / J13-20 |
| PCB 灯驱动 | VCC / GND | 3.3V / 公共地；板上两片级联、LED 电阻保留原焊接 |
| 原 BT05 ZS-040 蓝牙底板（可选） | TXD / RXD | J13-21 / J13-22；注意发送 TX 接 FPGA 接收端 |
| 原 BT05 底板 | VCC / GND | J13-11 的 5V / 公共地；信号为 3.3V，EN、STATE 不接 |
| 显示器 | HDMI | 一根 HDMI 线接开发板 HDMI 插座；不用接到排针 |

**压力片只有两根线怎么接：** 一根接 3.3V，另一根接 ADS1115 的 A0。A0 这个接点还要通过一个 10kΩ 电阻接地，并通过一个 100nF 电容接地。也就是“压力片的一端、A0、电阻上端、电容上端”接在同一个点；电阻和电容的另一端都接地。PCB 已经做好这个电路就只接压力片，不要重复加元件。按得越重，屏幕电压应越高，原标定最大力度为 3.235V。

**触摸铜片接哪里：** 铜片接 MPR121 的电极端，不直接接开发板。A 板 0～9 依次为 K0、S0、K1、S1、K2、K3、S2、K4、S3、K5；B 板 0～7 依次为 S4、K6、K7、X0、C0、C1、C2、C3。K 是 8 个白键、S 是 5 个黑键；X0/C0～C3 是控制片，保留原接法。

**保留原有小跳线：** PCM5102 的 SCK 接地、FMT 为低、XSMT 为高；原 I²C 的 SCL/SDA 上拉电阻接 3.3V。已经能正常发声和读取触摸的 PCB 不需要为本次摇杆升级修改这些连接。不要把 5V 接到 ADS1115 的 A0/A1 或 FPGA 信号脚。

## 临时 HDMI 接线诊断页

`./instrument/build.ps1 -WiringDebug` 构建独立的 `dist/instrument_wiring_debug.fs`，或打开 `instrument/instrument_wiring_debug.gprj`。它保留组合版外设通信与 B16 摇杆供电配置，音频/演奏控制核心保持复位，临时静音，屏幕标有 SILENT；下载后直接显示，无需触摸键或蓝牙切页。原 `dist/instrument_joystick.fs` 保留，排查后重新下载即可恢复演奏。器件 GW5AT-60B，操作 SRAM Program；下载不代表外设已恢复。

三行分别为 TOUCH A（SCL **E14** / SDA **E13**）、TOUCH B（SCL **A16** / SDA **A15**）、ADC（SCL **A20** / SDA **B20**）。ONLINE/OFFLINE 独立显示，不再只看到两块触摸板的合并结果。

- `SCL/SDA 0/1`：FPGA 端经同步、控制器释放总线至少八个时钟后采得的最近空闲电平；传输期间保留，不将正常传输的低电平误标为断线。尚未采到显示 `-`。这不是电压表，1 不证明有准确 3.3V，也不证明导线已接到 PCB。
- `LAST E...`：最近一次失败的原因，恢复 ONLINE 后仍保留。`FAIL 000..255` 是失败请求次数，饱和到 255；它包含初始化重试次数，不等于独立断线次数。重新配置/复位会清除历史。
- E0 NONE：本次复位后尚无记录；E1 NO ACK：从机未应答；E2 SCL LOW：时钟拉低超时；E3 SDA BUS：SDA 低引起总线恢复或超时；E4 TIMEOUT：其他事务超时。
- E5 CONFIG：读回配置不符；E6 OVERCUR：MPR121 报告 OVCF；E7 NOT RDY：ADS1115 转换等待超限。E6 不能据此直接推断 PCB 电源过流。
- PRESSURE/JOYSTICK 电压来自原共享 ADC，不是电源电压测量；ADC 离线显示 `-.--- V`。页面顶部 B16 提示仅说明固件启用了供电输出，不代表带载电压已测量。

先保持当前隔离接线不变，下载后等待 10 秒，记录三行的 ONLINE/OFFLINE、SCL/SDA、LAST 和 FAIL；间歇故障可隔几秒再记录一次。若三路一起失联，优先核对共地和 3.3V；仅一路失联则优先核对该行引脚及对应模块供电。数字诊断不能唯一判定某根杜邦线断路，仍需断电通断测量确认。不要为排查主动短接或拉低任何信号脚。

## 力敏输入优化及校准


保持原电路：3.3V → FSR → AIN0 → 10k → GND，AIN0 对地 100nF。此结构按压越大，电压越高。默认映射沿用最新实测标定： 0 mV 时 25% 表现音量、3235 mV 时 100%；主音量独立限制最终音量。它是全局表现控制，不是每个琴键独立力度。

新增 Q4 定点 IIR：每个有效 ADC 样本，增大方向追随差值的 1/4、减小方向追随差值的 1/8；保留小数避免整数量化停滞。零点附近 16 mV 死区抑制无压力噪声。Q9 音量增益每个音频采样最多移动 1/512，满行程约 7.9 ms，另加 ADC/滤波延迟和原有音频输出级的增益渐变时间（不是总响应时间 7.9 ms）。ADC 掉线平滑回到原主音量，重新接入也平滑过渡。

显示原始压力电压；ADC 内部通道切换后只更新各自的样本寄存器，屏幕不会交替显示摇杆电压。先在 HDMI 的原始压力 mV 显示上记录无压力电压和舒适最大力度电压，再调整顶层 `PRESSURE_ZERO_MV` 与 `PRESSURE_FULL_MV`，要求 0 ≤ ZERO < FULL ≤ 4095 且 FULL > ZERO+16；机械结构装好后再测。`JOYSTICK_CENTER_MV` 也可按实测中位调整，建议保留 3.3V 中位附近。当前采用可配置固定中位加回中确认，没有自动学习中心，避免开机拨住时错误校准。

## 高云打开与调试

1. 打开 `instrument/instrument_joystick.gprj`。本机已准备 `impl/instrument_joystick_process_config.json`；复制仓库到别处时，将 `config/joystick_process_config.json` 复制为该文件后再打开 IDE。
2. 器件 GW5AT-LV60PG484AC1/I0；顶层 instrument_top；Include Path 为 src；VCCX 1.8V；Use CPU as GPIO 开启。
3. 完整编译运行 `./instrument/build.ps1 -Joystick`，脚本完成综合、布局布线和时序检查后将新文件放到 `dist/instrument_joystick.fs`。只检查综合才加 `-SynthesisOnly`。
4. RTL 仿真使用可配置的 XSim 或 Icarus Verilog 和高云 GW5A 官方原语模型；本轮实际使用的工具、版本与通过项目见验证报告。这是 RTL 功能验证，不是布局布线后的时序仿真。
5. 断电接好线，确认电源和信号位置后上电。在 Gowin Programmer 选择 GW5AT-60B → SRAM Program，载入上述新文件。依次验收：触摸与原压力 → 摇杆回中/左右 → 按住颤音 → EC11 延音 → GUIDE。若要检查共享 ADC 掉线保护，先断电拔掉 ADC 的 SCL/SDA，再上电检查压力回退与摇杆停止切换；复原也先断电。

测试内容与本轮综合结果见 [验证报告](joystick_verification.md)。
