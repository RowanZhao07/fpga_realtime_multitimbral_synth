## FFT 评估结论

当前是 **4096 点、对称 Hann 窗、复数 radix-2 DIT FFT，输入为实数**，每级缩放，显示前 512 个频点，幅度近似为 `abs(real)+abs(imag)` 后取对数高度；不是全频段精密幅度分析仪。波形与频谱分别缓存。FFT 不阻塞逐样本发声。

| 方案 | 采集时间 | 频点间隔 | 取舍 |
|---|---:|---:|---|
| 当前 4096 点 | 83.886 ms | 11.921 Hz | 蝶形计算约 4.915 ms，再加输出与垂直消隐等待；可保留现有标尺 |
| 2048 点直接 FFT | 41.943 ms | 23.842 Hz | 刷新更快，邻近谱峰更难区分，必须修改标尺 |
| 1024 点直接 FFT | 20.972 ms | 47.684 Hz | 不适合用来证明低音区密集复音的独立谱峰 |
| 4096 实数 FFT：2048 复数内核+配对后处理 | 83.886 ms | 11.921 Hz | 最值得下一步 RTL 优化；保持窗口/分辨率，工作 RAM 理论减半 |
| 4 倍抽取+1024 点 FFT | 83.886 ms | 11.921 Hz | 采集时间不变，需抗混叠滤波；6 kHz 显示到新 Nyquist 仅约 103.5 Hz 余量，不是免费优化 |
| 少量 Goertzel 检测器 | 由观测窗决定 | 仍受窗口限制 | 适合额外的少数固定校准频率测量，不适合代替整个 512 柱频谱 |

算法原型 `instrument/tools/compare_spectrum_algorithms.py` 用静音、直流、Nyquist、随机信号和双音五组数据验证实数 FFT 重建与 NumPy rFFT 的复数结果一致。工作 RAM 估算为 131072→65536 bit；按一般复乘计、只后处理显示用 512 点，实乘次数上界 98304→47104，约少 52.1%（均不含 Hann 窗乘法）。这不是综合资源或板上速度实测；新位流仍用原已验证 FFT。

另验证八个固定音乐频率上的 Goertzel 能量与直接 DFT 的浮点结果，最大误差相对最大目标能量约 `1.23e-13`。八目标的递推乘法为 32768 次/窗，49 目标为 200704 次，512 目标为 2097152 次，未计末端能量运算。因此少目标可有优势，密集频谱仍适合 FFT；定点状态位宽、溢出、泄漏与检测阈值还需设计，不能把该原型当成已实现的音高识别器。[TI SPRA066：Goertzel 固定频率检测](https://www.ti.com/lit/pdf/spra066)。

频点间隔不等于能分辨的最小双音间隔，Hann 主瓣有宽度，低音相邻半音尤其不能只按“有 4096 点”断言分离成功。后续改成实数 FFT 还需完成定点缩放、舍入、成对 RAM 读取、频谱黄金值、HDMI 标尺和布局布线验证。[FFTW 实数 DFT 说明](https://www.fftw.org/fftw3_doc/One_002dDimensional-DFTs-of-Real-Data.html)、[Julius O. Smith：频率分辨率](https://dsprelated.com/freebooks/sasp/Frequency_Resolution.html)。
