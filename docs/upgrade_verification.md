`tb_voice_allocator` 覆盖 13 键同时起音、累积 32 声部及满载抢占；从撤销启动脉冲到有效结果的最大计数为 **829 拍**，含启动约 830 拍，约 16.6µs，低于 20.48µs 的采样周期，未出现 overrun。

最差 setup / hold / recovery / removal 裕量分别为 **0.142 / 0.046 / 0.107 / 0.651ns**，最小脉宽裕量 5.594ns；setup/hold 违规端点均为 0。时序通过但 setup 余量较小，后续接入传感器后必须重新综合和检查，不能按剩余 LUT 百分比推断一定能收敛。

混音使用固定额外 6dB 余量；相同主音量下单音电平约为旧版一半。尾音保持起音时音高与音色；满载先回收最轻释放声部，最后抢占最老声部，并对被抢占时的最后输出做 8 样本淡出。

- 41 项 RTL 回归通过，涵盖四音区、32 声部、延音、触摸恢复、压力、I²S、13 灯、HDMI、UART、曲谱原子上传及自动切换音区。

- 16 段 RTL PCM 音高估计最大误差约 0.095143Hz；8 音、13 音频谱及四音色三和弦均保留目标音，测试片段未削波，释放后归零。
- 动态泛音检查采用同一音色的早/晚真实 RTL 输出：电钢琴与金属音的二次泛音相对基波显著衰减，弦乐较缓慢，正弦保持低杂散。不是音箱录音或逐泛音独立包络模型。
- 数字触摸状态→解码后首个非零 I²S 样本，在 8 个事件相位中最大 **0.106830ms**。这是 T0 静音起音的数字段测试，不包含传感前端和模拟输出。
- 完整 HDMI 仿真画面已检查：纯色背景、GUIDE、三位步数、动态音名和声部数均可显示。
