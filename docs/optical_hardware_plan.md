## 条件接线

建议准备的 BSS138 电平板采用 HV=5V、LV=3.3V、两侧共地：白线分别接 HV1/HV2，LV1/LV2 经 1kΩ 到两路待分配 FPGA 输入。先在 FPGA 断开时测量通光/遮挡下低压侧的电压和边沿。具体商家模块须有正确的 MOSFET/上拉结构与已焊排针；这里没有替某一无规格商品做兼容保证。

如果卖家明确确认白线为无 5V 内部上拉的开集电极，也可省去电平板，直接用约 10kΩ 上拉到 3.3V；这是确认后的简化接法。不要把另一款 5–24V 模块或 12V 信号套入本接线。

GY-530 商品资料标注模块供电 2.8～5V、I²C 兼容 3～5V，但这不等于裸芯片的电压规格。优先确认模块带稳压和电平转换，使用 3.3V 接口并测量 SDA/SCL 上拉电压。只用一块 VL53L0X，默认 7 位地址 0x29；推荐独立 I²C，预留 XSHUT 方便异常复位。

本轮不增加顶层引脚、不改约束、不画新主 PCB。后续核对 Tang Mega 排针和现有 PCB 引出后再指定物理针号。先在外接转接板验证，跑通后再考虑将其并入下一版 PCB。

## 交互安排

- 电容键选择音符/和弦；依次穿过光束 A、B 产生一次扫弦事件，B、A 为反向；两次边沿间隔用于估计速度/力度。需要去毛刺、超时和手离开后重新武装，避免一挥手触发多次。
- 光束是快速触发输入，必须核实最大响应时间。总延迟还包含方向判别等待第二束的时间；不能只用单束的响应时间宣称整机 ≤5ms。
- VL53L0X 单手上下移动控制连续音色明暗，或在独奏模式控制有限范围滑音；平滑参数需兼顾跟手与抖动。失测短时保持，连续失测回到中性值，并显示状态。
- ST API 的标准配置默认 33ms、最小测量预算 20ms。因此它适合音色表达，不能当成 ≤5ms 起音传感器。手势测距延迟应单独报告，不与触键起音混为一项。
- 新控制仍由 HDL 实现，保留现有电容演奏、压力、延音、GUIDE、HDMI。已有器件能开始下一阶段验证，主要未决项是光电头的电气接口和固定结构。
