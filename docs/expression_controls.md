## 硬件与启动

当前逐线连接、U1 丝印方向、电源和外设安装状态见 [FPGA 与 PCB 接线清单](wiring_current.md)（含接线图和可打印 PDF）。其中 EC11 是否实际安装、VRy 是否接好尚未确认，VRx 已拔下排查。

若同一接线下诊断版稳定、演奏版 TOUCH LINK 失败计数持续增加，使用 [单文件分阶段对照](touch_isolation_20261101.md) 记录运行活动与掉线的关系；该版本用于定位，尚不是经过实板确认的修复。

沿用当前触摸板、FSR、EC11、KY-023、ADS1115、PCM5102 和显示器。唯一可选接线是 **KY-023 的 VRy → 当前 ADS1115 的 AIN2**；断电后连接，原有 VRx→AIN1、FSR→AIN0、供电及共地保持原接法，不增加 ADC。

Y 弯音上电默认关闭，VRy 仍悬空时可以试用 VIB 和音效，但不要启用 Y。接好 VRy 后，同时按一下 X0+C3（VIB）切换 Y；保持摇杆中位，屏幕由 `Y CENTER` 变为 `Y BEND ON` 后再拨动。再次按组合键关闭。也可发送 `Y1` / `Y0`。

启用后需要连续八次有效中位采样；中位允许 1.3～1.9 V，会学习实际中位，适配已有 GPIO 供电下的电压偏移。断开 ADC、触摸离线或进入校准模式会取消就绪，重新在线后需再次回中。软件不能可靠识别一根悬空模拟线，因此“默认关闭”不等于“启用后能自动检测断线”。

## 操作

| 操作 | 效果 |
|---|---|
| 按压 FSR | 公共音量表情，保留原 3235 mV 满压标定和渐变；不是逐键速度/力度传感 |
| 摇杆 Y 上下 | 连续弯音，约 -2 至 +2 半音，60 mV 中位死区，逐采样限速；回中回到原音高 |
| 按住 C3/VIB 或摇杆 SW | 颤音，两者都有效，松开两者后关闭 |
| X0+C3 | 切换 Y 弯音使能，组合期间不触发 VIB；按住不重复切换 |
| 摇杆 X 左右 | 保留离散换音区，回中再触发；GUIDE 的自动音区优先 |
| C0 短按 | 保留四音色切换；已经发声的声部保留原音色 |
| C0 长按约 1 s | OFF → DELAY → REVERB → CHORUS → OFF；长按不同时切换音色 |
| EC11 | 保留原延音开关与 16 档衰减速度 |

滑音在这里是全局连续弯音：保持当前按键即可平滑改变音高，旧延音也随之变化；不是跨键自动 portamento。力度动态、连续音高和颤音可以独立控制，音色和延音另行操作。

串口仍为 9600/8N1，一条命令收到 K 后再发下一条：

| 命令 | 功能 |
|---|---|
| F0 / F1 / F2 / F3 | 关闭 / 延迟 / 混响 / 合唱 |
| Y0 / Y1 | 禁用 / 启用 Y 弯音 |
| E0 / E1 | 兼容旧命令，切到关闭 / 延迟 |
| T0～T3、V0～V4096 | 原音色、主音量命令 |

F/Y 仅由新表情版解析，原工程会拒绝；不要把串口 K 回应时间当成音频延迟。

## 音效与资源取舍

音效全部在 FPGA 内逐样本处理，仍为单声道信号复制到 I²S 左右声道。

- 延迟：原 16384 样本、约 335.54 ms 的一次前馈回声，湿声为 1/4。
- 混响：四个带低通阻尼的反馈梳状滤波器（1493/1601/1747/1867 样本，反馈 0.75），串联两个 Schroeder 全通扩散器（211/73 样本，系数 0.5）。这是简化小房间混响，不是卷积混响。
- 合唱：2048 深度环形 RAM，512～约 768 样本的可变延迟，8 位小数线性插值，约 0.7014 Hz 三角 LFO，湿声最大 1/4。
- 新混响/合唱各用 128 个音频采样渐入/渐出。内存上电/复位未写位置屏蔽，递归滤波向零截断以抑制定点残留直流；校准模式绕过效果。
- 输出仍通过原软限幅和主音量/压力控制，多音或音效峰值过大时 LIMIT 可能亮起。没有增加自动按声部数调节音量。

结构依据：[Schroeder 混响](https://www.dsprelated.com/freebooks/pasp/Schroeder_Reverberators.html)、[合唱与时变延迟](https://www.dsprelated.com/freebooks/pasp/Chorus_Effect.html)。均为标准 DSP 方法，本项目工作是适配现有硬件、定点流水与控制集成，不宣称发明这些算法。

## TOUCH OFFLINE 现场取证（EXPR L1）

2026-10-31 用户反馈：接线保持不变时，静音 `instrument_wiring_debug.fs` 的两路 TOUCH 和 ADC 都 ONLINE、FAIL 000，摇杆中位显示 1.672 V；新表情版出现 TOUCH OFFLINE、ADC 正常，旧演奏版也会出现掉线。此前重新插过线，但不能据此认定接错，也不能把 A2/A3 相连认定为触摸掉线根因。该照片是诊断版正常状态的证据，不是演奏版故障时的总线记录。

诊断版和演奏版的触摸引脚、MPR121 初始化及 I²C 时序相同，构建配置除输出名称外一致。诊断版将演奏核心保持复位；演奏版正常运行合成、音频输出等逻辑。换文件会清除故障历史，因此需在演奏版直接观察，不能通过切回诊断版的 E0 推断原先没有故障。两路 `chip_online` 取与后形成总的 TOUCH 状态，任一路离线都会释放全部琴键。

`EXPR L1` 在完整演奏版中保留三路控制器的诊断数据。右上角版本标识为 **EXPR L1**；TOUCH 离线时，右下角自动显示 **TOUCH LINK**，无需触摸按键或串口命令：

- `A1 E0 F000` / `B0 E1 F023`：A/B 后的 1/0 是该触摸板当前在线状态；E 为最近故障码；F 为本次复位后失败请求次数（含重试，最大 255）。
- 下一行是故障名称及 `S` / `D`：最近稳定空闲时的 SCL/SDA 电平，`-` 表示尚无有效空闲采样；数字 1 不等于测得 3.3 V。
- E0 尚无故障记录；E1 无应答；E2 SCL 拉低超时；E3 SDA 总线恢复/超时；E4 其他超时；E5 配置读回不符；E6 MPR121 OVCF 状态，不能直接解释成 PCB 电源过流。
- 自动重试继续运行。恢复后返回 GUIDE/UART 面板，控制器内部仍保留故障历史，重新下载/复位才清除。

这次修改只补充故障可见性，没有改变触摸扫描参数、故障退出判定或将 ONLINE 强制置位，**不代表掉线根因已修复**。用于复核的是完整演奏工作负载下的错误码。下载后保持接线不动；如果 OFFLINE 持续超过启动阶段，拍下完整屏幕，尤其是右下角 A/B 两行，再决定检查哪一路。不要求先拆焊或更换触摸板。

新增 `tb_expression_touch_link` 将两块 MPR121 总线模型和三通道 ADC 模型接到完整顶层，不强制注入 online/touched；检查正常发声、B 无应答时 A/ADC 继续工作、故障码经过跨时钟传递到屏幕，以及 SCL 故障和 OVCF 后恢复。启动/重试时间、触摸总线分频和显示消隐在该仿真中加速；它不验证电源、接触电阻、串扰或实板波形。

L1 验证：上述完整顶层仿真、`tb_expression_screen` 的正常/离线页面与恢复、原 `tb_wiring_top` 三项通过；两张 800×600 仿真截图已查看。布局布线 setup/hold 违例均为 0，最小 setup 裕量为 0.043 ns，仍通过现有时序门禁但余量较小；未更改时钟约束。资源为 Logic 31,544/59,904、Register 8,091/60,780、BSRAM 57/118、DSP 43/118。原 `ref_clk_d` 通用时钟布线告警仍保留。证据、旧版本备份及用户诊断照片保存在 `.local/touch-offline-20261031/`；这三项检查不是重新运行最初的 31 项验收。
