# 表情控制与数字效果

当前版本 EXPR M3 8T。音频由 FPGA 内的定点数据通路逐样本生成；表情参数在采样边界进入控制，显示与音频共享同一输出 PCM。

## 演奏输入

| 输入 | 映射与处理 |
|---|---|
| FSR402B → ADS1115 AIN0 | 全局音量表情；0～3.235 V 映射为 25%～100%，配合滤波、死区与增益渐变 |
| 摇杆 X → AIN1 | 四档音区，回中后接受下一次切换；新音锁存音高，旧尾音保持 |
| 摇杆 SW 或 C3/VIB | 按住颤音，松开恢复 |
| 摇杆 Y → AIN2 | 可选全局连续弯音，约 ±2 半音；上电关闭，以 UART `Y1/Y0` 开关 |
| EC11 按压 / 旋转 | 延音开关 / 16 档衰减；带同步与去抖 |
| C0/TONE 短按 / 长按 | 八音色循环 / OFF → DELAY → REVERB → CHORUS |

Y 弯音启用后收集八次有效中位采样，学习 1.3～1.9 V 内的中位，使用 60 mV 死区和逐样本限速。连接方法见[接线清单](wiring_current.md)。X0+C3 用于节拍器开关。

## 样本域效果

| 模式 | 结构 | 参数 |
|---|---|---|
| DELAY | 单次前馈延迟 | 16,384 样本，约 335.54 ms；湿声 1/4 |
| REVERB | Schroeder 混响 | 四条阻尼反馈梳状支路，延迟 1493/1601/1747/1867；两级全通 211/73 |
| CHORUS | 调制分数延迟 | 2048 深度 RAM；512～约 768 样本，8 bit 小数插值，约 0.7014 Hz LFO |

混响与合唱切换采用 128 样本渐入／渐出，历史缓存有效标记隔离未填充内容。递归滤波向零截断，抑制定点残留。合成声部先混合、经过效果及软限幅，再施加主音量和压力；节拍声在之后独立混入并做有符号饱和。I²S 左右声道承载相同 PCM。

音频运算与 FFT 分别调度。4096 点分析窗不阻塞 1024 时钟的采样帧；波形和 XY 的 3X 只改变显示坐标。

## UART

9600 baud、8N1，逐行发送，收到 `K` 后再发下一条；`E` 表示拒绝。

| 命令 | 功能 |
|---|---|
| `F0/F1/F2/F3` | 关闭／延迟／混响／合唱 |
| `Y0/Y1` | 禁用／启用 Y 弯音 |
| `E0/E1` | 兼容关闭／延迟 |
| `T0`～`T7` | 音色选择 |
| `V0`～`V4096` | 主音量 |
| `H0/H1` | 延音开关 |

算法采用直接数字合成、ADSR 和标准延迟网络；实现重点是定点位宽、RAM 调度、参数过渡与统一帧边界。源代码见 `polyphonic_engine.v`、`envelope_adsr.v`、`expression_effects.v` 与 `instrument_core.v`。验证与版本见[M3 优化验证](scheduler_optimization.md)。
