## U1 方向：最重要的定位

按保存的 PCB 元件面丝印与焊盘坐标，**“U1”字样附近的端头圆焊盘是 U1-2 → E13 / J13-2**；同一对相邻的**方焊盘是 U1-1 → E14 / J13-1**。不把“靠 U1 那一侧”笼统称为 1 脚。焊接面会镜像，以方焊盘 1 脚和针号为准。尚未通过实物近照逐针确认。

**U1-6～U1-10 在保存的 PCB 设计中没有布线。** 开发板 J13 对应针有信号，但只插 PCB 同号焊盘并不会自动接到摇杆或编码器。

## 电源与公共地

| 源头 | 去向 | 说明 |
| --- | --- | --- |
| FPGA J13-11 / +5V | PCB U1-11 / +5V | 用户确认；同网连接 PCB USB1 的电源端 |
| FPGA J13-12 / GND | PCB U1-12 / GND | 摇杆、ADC、触摸、DAC 模块和可选串口共地 |
| PCB +5V → U7-3 | AMS1117-3.3 → U7-2/4 / +3.3V | 板内稳压；U7-1 接地 |
| PCB +3.3V | P3-1、P2-1、U2-1、U5-16、U6-16、FSR1-2 | 触摸、ADC、LED 逻辑及压力分压供电 |
| FPGA J13-9 / B16 | 摇杆印字 5V / VCC | 当前固件加载后输出约 3.3V；只带这一只低功耗摇杆 |

B16 是加载对应固件后输出高电平的 3.3V GPIO，不是固定电源轨。仅沿用当前一只低功耗摇杆，不给 PCB 或其他模块供电，不与 PCB 5V、3.3V 或外部电源并联。J13-11 是 5V，与 B16 区分。

## 摇杆

| 模块标签 | 应接位置 | 说明 |
| --- | --- | --- |
| 5V / VCC | J13-9 / B16 | 这是模块印字；当前按约 3.3V 使用，不是接 J13-11 |
| GND | 公共地 / J13-12 | 测量 VRx、VRy 时黑表笔接此模块 GND |
| VRx（有时印 URx） | ADS1115 A1 = PCB U2-8 | 用户已拔下排查；恢复前先确认模块端电压正常 |
| VRy（有时印 URy） | ADS1115 A2 = PCB U2-9 | 可选；实物是否接好尚未确认；Y 弯音默认关闭 |
| SW | J13-23 / A19 | 按下接地；用户曾确认可以触发颤音 |

VRx/VRy 是模拟电压，必须接 ADS1115，不能接任意空闲 FPGA 数字针脚。A2/A3 连点成立的条件是两者只有同一只 VRy 信号，A3 没有其他连接；当前单端 AIN2-GND 配置适用。

## PCM5102 / 音频输出

| PCB 排针 | 模块信号 | 连接 |
| --- | --- | --- |
| P4-1 | SCK / MCLK | GND；本工程不提供外部 MCLK |
| P4-2 | BCK | C15 / U1-3 / J13-3 |
| P4-3 | DIN | B13 / U1-5 / J13-5 |
| P4-4 | LRCK / LCK | C14 / U1-4 / J13-4 |
| P4-5 | GND | 公共地 |
| P4-6 | VIN | PCB +5V；仅适用于现有带稳压模块 |

CN1：1=LOUT，2=AGND，3=R-OUT，4=AGND，5=3.3V，6=FMT，7=XSMT，8=DEMP，9=FLT。FMT 经 R18 接地，XSMT 经 R17 上拉 3.3V；DEMP/FLT 沿用模块现有配置，不新增未核实的跳线。

音频输出接有源音箱 AUX 或功放线路输入。AGND 接模块音频地，不当音频信号使用。P4-6 的 5V 适用于现有带稳压模块，不适用于裸 PCM5102 芯片。
