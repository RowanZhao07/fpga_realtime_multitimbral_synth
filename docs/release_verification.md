## 本次发布回归

5 项针对性 RTL 回归通过：`tb_display_gain`、`tb_expression_allocator`、`tb_expression_core`、`tb_expression_latency`、`tb_expression_top`。覆盖 3X 全输入、32 声部负载、实际 UART 控制、数字响应及官方原语支持的顶层链路。

Python 测试：串口工具 11 项、曲谱 3 项、测量数据处理 4 项通过。发布审计核对位流及输入哈希、38 个放置后端口、资源与时序，并确认 UI 修订保持音频与引脚源文件一致。
