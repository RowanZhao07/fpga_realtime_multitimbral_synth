# 最终发布验证 EXPR M2 8T

发布日期：2026-11-04。活动工程 `instrument_expression.gprj`，顶层 `instrument_top`；工具 Gowin 1.9.12.03、XSim 2025.1 与 GW5A 官方仿真原语。

## 数字实现

| 指标 | 结果与条件 |
|---|---|
| 独立声部 | 32 组相位、频率、音色、包络、年龄与所属键状态 |
| 采样率 | 50 MHz / 1024 = 48,828.125 Hz，RTL 标称值 |
| 合成负载 | 密集起音、尾音与抢占测试，最重帧 829 / 1024 时钟 |
| 声部运算容量 | 32 × 48,828.125 = 1,562,500 声部采样 / 秒 |
| 采样帧余量 | 195 时钟，19.04%；指帧调度预算，与 STA 余量分别计量 |
| 数字核心响应 | 47.93～65.87 μs，T0、节拍器关闭、8 个触发相位 |
| ADC 更新 | 三通道、100 kHz I²C 模型：9.97572 ms / 通道 |
| FFT | 4096 点 Hann；频点间隔 11.920928955 Hz；采集窗 83.88608 ms |
| 节拍器 | 5 拍号、40～240 BPM；固定 BPM 相位累计偏差小于 1 样本 |

32 声部由独立状态和活动声部负载回归验证：[`tb_voice_allocator.sv`](../instrument/sim/tb_voice_allocator.sv)检查满载、尾音及抢占，[`tb_eight_timbres.sv`](../instrument/sim/tb_eight_timbres.sv)检查混合音色、32 个活动声部与输出有效性。现有频谱校准模式使用 8 路独立正弦音。数字核心响应从控制状态入口计时至完整 I²S 样本，8 相位原始数值见[CSV](evidence/latency_expression.csv)。现场 **472 μs、1.75 ms** 两项电气事件读数及示波器原图见[响应测量](latency_measurement.md)。

## 回归分层

| 版本 | 验证内容 |
|---|---|
| 八音色 | 17 项定向 RTL 回归；164,211 帧八音色 I²S 解码；32 声部负载；八音色 × 16 档衰减；串口工具 12 项 Python 测试 |
| M1 节拍器 | 14 项 RTL 回归；组合键、5 拍号、连续调速、频谱峰值压缩、707 bit 状态邮箱、触摸恢复与完整界面 |
| M2 节拍声增强 | 3 项定向 RTL 回归：音频、核心 I²S、屏幕；8767 帧 I²S；主音量静音、关闭旁路、正负饱和 |
| M1 / M2 对照 | 293414 个采样点对齐，节拍声精确 4 倍，拍点与强弱关系不变 |

各组结果按对应源码版本保存。M2 更改节拍声缩放与发布标识，原演奏控制、音色与引脚保持。最终构建的 56 个输入哈希已与发布源码核对。
