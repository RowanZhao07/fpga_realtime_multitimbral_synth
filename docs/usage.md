# 演奏与曲谱操作

当前配置：EXPR M2 8T，保留 3X 显示缩放。节拍声相对 M1 振幅提高 4 倍（约 +12 dB）。上电默认 T1 电钢琴音色、主音量 50%、延音关闭、衰减 03 档。

| 操作 | 功能 |
|---|---|
| 13 个触摸琴键 | C 到高 C 的半音阶 |
| C0 短按 / 长按 | 循环切换八种音色 / 循环切换 OFF、DELAY、REVERB、CHORUS |
| C1 / C2 | 音量减 / 加 |
| C1 & C2 同时长按 | 开关 GUIDE |
| 摇杆左右拨动 | 切换四档音区；回中后接受下一次切换 |
| 摇杆按键或 C3 | 按住开启颤音 |
| 压力片 | 连续调节整体音量；全局表情控制 |
| EC11 按压 / 旋转 | 开关延音 / 16 档尾音衰减 |
| X0 | 单独按住检查 13 路琴键灯 |
| X0 + C0/TONE，保持约 0.5 s | 切换 2/2、2/4、3/4、4/4、6/8 拍号 |
| X0 + C3/VIB，保持约 0.5 s | 开关节拍器，默认关闭、120 BPM、4/4 |
| X0 + C2/VOL+ 或 C1/VOL− | 持续调速，每 0.1 s 变化 1 BPM，40～240 |

四档音区为 C3～C4、C4～C5、C5～C6、C6～C7。新音锁定音高与音色，换音区或换音色时旧尾音保持原设定。

| 编号 / HDMI 名称 | 合成音色 | 演奏特点 |
|---|---|---|
| T0 / SINE | 正弦 | 纯音基准 |
| T1 / EPIANO | 电钢琴 | 较快起音，谐波随尾音衰减 |
| T2 / STRINGS | 弦乐 | 缓慢起音，持续发声 |
| T3 / METAL | 金属打击 | 明亮起音，打击衰减 |
| T4 / FLUTE | 长笛 | 较柔和起音，持续的基音与少量谐波 |
| T5 / ORGAN | 管风琴 | 快速起音，持续的八度谐波，短释放 |
| T6 / PLUCK | 拨弦 | 明亮拨弦起音，快速变暗并衰减 |
| T7 / BASS | 贝斯 | 较厚实起音，较慢的音量和谐波衰减；低音区更适合试听 |

以上是数学波表与包络形成的合成近似音色，不是乐器录音采样。C0 在松开时切换，T7 后回到 T0；上电默认 T1。开发板闲置时 L5～L8 显示组内编号，L3 点亮表示 T4～T7；PCB 的 13 个琴键灯仍显示按键／GUIDE。版本与验证见[八音色扩展](eight_timbres.md)。

GUIDE 内置《遇见》76 音片段。绿色琴键与 LED 标出下一目标，按对立即推进，演奏者自行掌握节奏；连续同键需松开后重新触摸。完成显示 DONE。GUIDE 自动选择目标音区，关闭后恢复手动音区。

## 串口与曲谱

接口为 9600 baud、8N1。每条命令以 LF 或 CRLF 结束，返回 K 后发送下一条，E 表示拒绝。

| 命令 | 功能 |
|---|---|
| `?` | 通信检查 |
| `T0`～`T7` / `V0`～`V4096` | 音色 / 音量；`T8` 及以上拒绝 |
| `E0/E1`、`H0/H1`、`G0/G1` | 延迟、延音、GUIDE 开关 |
| `R` | 恢复内置曲谱并重新开始 |
| `N`、`Axxxx`、`Z` | 开始上传、追加键位掩码、原子提交 |
| `O3`～`O6` / `U1`～`U255` | 上传步骤的音区 / 十六分音符时值 |
| `B40`～`B240` | 计时曲谱节拍速度 |
| `D0/D1` | 演奏页 / 诊断页 |

曲谱容量为 512 步。文本支持 `C4:2`、`C#5:1`、`C4+E4+G4:4`、`REST:2`。工具先检查音域、和弦范围及格式，再上传；只有 Z 成功后才替换旧曲谱。复位后恢复内置曲谱。曲谱提供目标提示，由触键实时产生声音。

```powershell
python instrument/tools/serial_control.py --score assets/scores/yujian.txt --bpm 93 --emit
python instrument/tools/serial_control.py --port COM7 --score assets/scores/yujian.txt --bpm 93
```

实际串口传输需安装 `pyserial`；COM 口应对应数据串口。详细协议与表情参数见[表情控制](expression_controls.md)。

## 屏幕含义

波形为送往 I²S 的 PCM；512 点窗口对应 10.486 ms。波形与 XY 轨迹的 3X 只改变绘图幅度。李萨如坐标分别使用当前 PCM 和延迟 32 点的 PCM，表示同一声音的延迟轨迹。FFT 使用原始 PCM、4096 点 Hann 窗及前 512 个频点。VOICES 显示实际活动声部数；琴键条显示包络与 GUIDE 目标。

节拍器强弱拍、6/8 的附点四分计拍单位及新界面见[节拍器说明](metronome.md)。GUIDE 的 BPM 仍独立，由串口 B 命令设置。X0+C3 已改为节拍器，Y 弯音使用串口 Y0/Y1。
